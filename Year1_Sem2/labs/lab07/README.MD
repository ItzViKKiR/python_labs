# ЛР-7 — Консольное приложение
Предметная область

## Недвижимость

## Объекты

Система управления недвижимостью:

- объекты аренды
- объекты с ипотекой

## Реализованные возможности
CLI-интерфейс

Консольное приложение с интерактивным меню:

1. Зарегистрировать недвижимость
2. Показать всю недвижимость
3. Найти по владельцу
4. Поменять владельца
5. Заказать выписку ЕГРН
6. Удалить объект
7. Фильтр доступной недвижимости
8. Сортировка недвижимости
0. Выход


### При запуске:

- данные автоматически загружаются из JSON-файла

### При выходе:

- данные автоматически сохраняются
## Валидация

Реализована проверка:

типов данных
- email
- меню
- числового ввода
- отмены действий
- Поддерживаемые email-домены
- gmail.com
- yandex.ru
- edu.misis.ru
## Отмена действий

Во всех пунктах можно:

0 — отмена действия

После чего приложение спрашивает подтверждение и возвращает пользователя в главное меню.
